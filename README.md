### 🧑‍💻 Sobre mí

Diseño y construyo sistemas **full stack de punta a punta**, con foco en **backend, arquitectura de software** y en **liderar equipos técnicos**. Me gusta tomar productos desde la idea hasta producción: modelar el dominio, definir la arquitectura, escribir el código y dejar la operación automatizada.

- 🏗️ Arquitectura: monolitos modulares, DDD, CQRS, multitenancy y offline-first
- 🧭 Liderazgo técnico: decisiones de arquitectura, estándares, code review y ADRs
